# Withered Foxy Jumpscare

[Windhawk](https://windhawk.net/) mod that randomly shows the FNAF 2 Withered Foxy jumpscare fullscreen on top of all apps.

- Chance: 1 in 100000 per second by default (configurable)
- Transparent background, works over fullscreen apps
- Image and sound are downloaded automatically on first run
- Test hotkey: `Ctrl+Alt+F`

## Install

1. Open Windhawk and click **Create a new mod**.
2. Replace the code with [`withered-foxy-jumpscare.wh.cpp`](withered-foxy-jumpscare.wh.cpp).
3. Click **Compile Mod**, then **Exit editing mode**.
